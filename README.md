# Ловец запросов — лайт

Следит за группами в твоём Телеграме, находит людей, которые **прямо сейчас** ищут то, что ты
делаешь, оценивает их (0-100, с объяснением) и присылает горячих в Телеграм: кто, где, что написал,
почему такой балл, готовый заход и ссылка на пост. Писать им ты будешь сам: автоотправки нет.

Панели нет, всё нужное для решения лежит в самом уведомлении.

## С чего начать

Открой свой офис (Claude Code) и скажи:

> прочитай `onboarding/SKILL.md` из папки ловца и настрой его

Дальше помощник ведёт сам. Что может, делает сам; где нужен ты, объясняет и ждёт: вход в Телеграм,
ключи, вступление в чаты. Один заход, примерно час-полтора, твоих рук минут 15-20. Можно прерваться:
помощник по `doctor.py` видит, где остановились.

Офиса нет: тот же файл `onboarding/SKILL.md` можно дать любому помощнику, который умеет запускать
команды (Claude Code, Codex, Cursor). Скиллы в офис при этом не ставятся, остальное работает.

## Что понадобится

- Linux или Mac (на Windows через WSL), Python 3.9+
- Claude Code (им оценивается находка; идёт в твою подписку, по умолчанию немного)
- Телеграм-аккаунт и 10-30 тематических групп, где ты состоишь (ловец ищет только в них)
- Свой Телеграм-бот для уведомлений (создаётся за 3 минуты в @BotFather, помощник проведёт)

## Что внутри

| Папка | Что |
|---|---|
| `onboarding/` | `SKILL.md` + файлы шагов: пошаговая настройка для помощника |
| `lovec/` | код: поиск, оценка, уведомления, прогон, проверка готовности, расписание |
| `skills/lovec-daily/` | повседневный скилл: что нового, подкрутить фразы, разобрать находку |
| `templates/` | заготовки профиля ниши и поисковых фраз |
| `docs/` | как устроено, как ставятся баллы, безопасность и этика |

Личное (ключи, вход в Телеграм, найденное) лежит в `data/` и в git не попадает.

## Чего здесь нет намеренно

- **Панели, стадий, кнопок в уведомлении.** Лайт-версия; стадии при желании ведёт твой офис.
- **Автоотправки.** Первое сообщение живому человеку от робота читается как спам.
- **ВКонтакте и Threads.** Только Телеграм.
- **Чужих данных.** Ни ключей, ни баз, ни сессий автора в комплекте нет.
