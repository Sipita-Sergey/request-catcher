# Шаг 1 — установка (doctor: `python`, `deps`, `claude`)

**Цель:** рабочее окружение и пустые заготовки в `data/`. Делаешь ты.

## Что делаешь

```bash
cd <КОМПЛЕКТ> && bash setup.sh
```

Создаёт `venv/`, ставит Телетон (библиотека для Телеграма), кладёт в `data/` три заготовки: `niche.md`
(профиль ниши), `phrases.txt` (поисковые фразы), `.env` (настройки и ключи, права 600). `data/` в git не
попадает: там всё личное.

Сразу после установки запиши `data/setup-state.md`: офис (путь или «нет»), машина, правила офиса
из шага 0 одной-двумя строками, дата. Если сессия прервётся, следующий заход начнётся с этого файла
и с `doctor.py`, а не с нуля.

Проверка: `./venv/bin/python lovec/doctor.py --offline` → пункты `python`, `deps` зелёные.

## Если что-то пошло не так

| Что видно | Что значит | Что делать |
|---|---|---|
| `нет python3` / «старше 3.9» | на машине нет подходящего Python | человек ставит Python 3.9+ (на Mac — `brew install python`, на Ubuntu — `sudo apt install python3 python3-venv`); команду выдай по правилам офиса |
| «не создалось окружение… python3-venv» | на Debian/Ubuntu нет модуля venv | `sudo apt install python3-venv` — нужны права администратора; сначала проверь командой, есть ли они у пользователя, и скажи честно, если не уверен |
| pip не может скачать пакеты | нет интернета или он закрыт | проверь `curl -sI https://pypi.org` ; прокси/VPN — задача человека |
| `claude` не найден (`doctor`: `claude`) | оценка находок вызывает Claude Code | если ты работаешь в Claude Code, он есть: покажи `command -v claude` и впиши путь `./venv/bin/python lovec/envset.py LOVEC_CLAUDE_BIN <путь>`. Нет совсем — человеку ставить Claude Code и входить в него; без него ловец искать будет, а оценивать нет |

## Что сказать про лимит подписки

Оценка идёт в той же подписке Claude, что и работа человека. По умолчанию ловец тратит немного:
мелкая модель (haiku) разбирает пачки по 15 сообщений, не больше 150 оценок за прогон, а сильная
(sonnet) подключается только для горячих, чтобы написать заход. Если лимит кончится, ловец не сломается:
найденное подождёт следующего прогона, а человеку придёт одна тревога в сутки.
