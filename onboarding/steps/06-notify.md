# Шаг 6 — уведомления в Телеграм (doctor: `bot`, `chat_id`, `notify_test`)

**Цель:** горячие запросы приходят человеку в Телеграм сообщением от его собственного бота.
Панели нет, поэтому уведомление должно быть самодостаточным: кто, где, что написал, почему такой
балл, готовый заход, ссылка на пост.

**Бот отдельный, не из офиса.** Если у офиса уже есть Телеграм-бот, его токен не берём: запросы
утонут среди служебных сообщений, а оборвать связь с ловцом при смене токена офиса будет легко.

## А. Бот (делает человек, ~3 минуты)

1. В Телеграме открыть **@BotFather**, написать `/newbot`.
2. Придумать имя (любое) и логин бота (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен**, длинную строку с двоеточием. Токен это пароль бота: в чат его не
   вставляем. Команда для человека:

   ```bash
   cd <КОМПЛЕКТ> && ./lovec/set-secret.sh TG_BOT_TOKEN
   ```

   Он увидит `✅ TG_BOT_TOKEN записан в data/.env`. Если токен всё-таки попал в чат, скажи вслух, что
   его надо пересоздать (BotFather → `/revoke`), и дальше вводите командой.
4. **Открыть своего бота в Телеграме и нажать Start.** Без этого бот не может писать первым, это
   правило Телеграма.

## Б. Куда слать (делаешь ты)

```bash
cd <КОМПЛЕКТ> && ./venv/bin/python lovec/notify.py setup
```

Печатает `chat_id=123456789 (имя)`. Запиши его:

```bash
cd <КОМПЛЕКТ> && ./venv/bin/python lovec/envset.py TG_NOTIFY_CHAT <chat_id>
```

**Личка с ботом** это основной вариант: проще и надёжнее. **Группа с темами** тоже возможна, если у
человека уже есть место для уведомлений: он добавляет бота в группу, пишет там что-нибудь, `setup`
покажет id группы (начинается с `-100`). Чтобы слать в конкретную тему, нужен её номер: он стоит
вторым числом в ссылке на любое сообщение из темы (`t.me/c/ГРУППА/ТЕМА/СООБЩЕНИЕ`), записывается
`envset.py TG_NOTIFY_THREAD <тема>`.

## В. Проверка

```bash
cd <КОМПЛЕКТ> && ./venv/bin/python lovec/notify.py test
```

Спроси человека: «пришло сообщение "Ловец запросов подключён"?» Только его «да» закрывает шаг
(`notify_test` в doctor ставится при успешной отправке, но без подтверждения человека не считай шаг
закрытым: сообщение могло уйти не туда).

## Грабли

| Что видно | Что значит |
|---|---|
| `notify.py setup`: «боту пока никто не писал» | человек не нажал Start или открыл не того бота |
| `Forbidden: bot can't initiate conversation` | то же самое |
| `Unauthorized` | токен введён с ошибкой: повторить `set-secret.sh TG_BOT_TOKEN` |
| `setup` пуст, хотя Start нажат | у бота включён webhook или его уже читает другая программа: создать для ловца нового бота |
| сообщение в группу не уходит | бот не админ в группе с ограничениями, либо `chat_id` без минуса |
