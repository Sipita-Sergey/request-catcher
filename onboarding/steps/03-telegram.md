# Шаг 3 — Телеграм-аккаунт (doctor: `tg_creds`, `tg_login`)

**Цель:** ловец входит в Телеграм человека и ищет от его имени. Здесь больше всего ручной работы,
ведёшь внимательно, по одному действию.

## Что сказать человеку до начала (обязательно)

> Ловец только **читает**: ищет по твоим группам. Он ничего не пишет от твоего имени, никуда не
> вступает и не ставит реакций. Вход хранится в файле на этом компьютере (`data/session.session`);
> это ключ от твоего аккаунта, поэтому его нельзя пересылать и выкладывать. Выйти в любой момент:
> Телеграм → Настройки → Устройства → завершить сеанс. В списке устройств появится новая сессия,
> это нормально.

Основной аккаунт подходит: действий, за которые Телеграм наказывает, ловец не совершает.

## А. Ключи приложения (делает человек, ~5 минут)

1. Открыть **https://my.telegram.org**, войти по номеру (код придёт в приложение Телеграм).
2. «API development tools» → создать приложение: название и короткое имя любые, платформа любая.
3. Записать две вещи: **api_id** (число) и **api_hash** (длинная строка).

Страница иногда отвечает ошибкой при создании приложения, это бывает. Повторить через несколько минут,
в другом браузере, без расширений-блокировщиков.

Когда человек назвал **api_id** и номер телефона (в формате `+79991234567`): это не секреты, запиши сам:

```bash
cd <КОМПЛЕКТ> && ./venv/bin/python lovec/envset.py TG_API_ID <число> && ./venv/bin/python lovec/envset.py TG_PHONE <+7…>
```

**api_hash пиши только скрытым вводом**, не принимай его в чат. Если человек уже вставил его в чат,
скажи, что лучше пересоздать приложение, и дальше вводите через команду. Команда для человека:

```bash
cd <КОМПЛЕКТ> && ./lovec/set-secret.sh TG_API_HASH
```

Что он увидит: подсказку «Вставь значение…» и после Enter `✅ TG_API_HASH записан в data/.env`.

Проверка: `doctor.py --offline` → `tg_creds` зелёный.

## Б. Вход (код вводит человек)

1. Ты: `cd <КОМПЛЕКТ> && ./venv/bin/python lovec/login.py request`
   → «код отправлен в Телеграм». Код придёт **в приложение Телеграм** сообщением от «Telegram»
   (не СМС).
2. Скажи человеку: «сейчас в Телеграме придёт код. Не пересылай его никому и не пиши мне: Телеграм
   аннулирует код, отправленный через сам Телеграм. Введи его в терминале». Команда для человека:

   ```bash
   cd <КОМПЛЕКТ> && ./lovec/login.sh code
   ```

   Он увидит подсказку, вводит код (на экране ничего не появляется), Enter.
3. Результаты:

| Что напечатано | Что делать |
|---|---|
| `✅ вошли как @…` | готово |
| `🔐 включён облачный пароль` | человеку: `cd <КОМПЛЕКТ> && ./lovec/login.sh password` (пароль двухэтапной проверки; если забыл, восстанавливается через Телеграм, не через нас) |
| `⛔ код неверный` | повторить `login.sh code`, код действует недолго |
| `⛔ код устарел` | ты: снова `login.py request`, человеку снова `login.sh code` |
| `FloodWait` / «слишком много попыток» | подождать указанное время, не долбить повторами |

Проверка: `./venv/bin/python lovec/login.py status` → `✅ вход есть: @…, групп: N`.

## Грабли

- Номер не в международном формате: код не придёт. Нужен `+` и код страны.
- Скрытый ввод (`login.sh`, `set-secret.sh`) работает в настоящем терминале (Terminal, iTerm, окно
  терминала в среде). В окне чата помощника он может не сработать: тогда человек открывает обычный
  терминал, скажи ему об этом словами и дай ту же команду.
- Сессия «слетела» позже (человек завершил сеанс, сменил пароль): ловец пришлёт тревогу, лечится
  повтором шага Б.
