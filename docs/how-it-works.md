# Как устроен ловец

```
твои группы в Телеграме
        │  поиск по фразам (search.py, раз в час)
        ▼
   база data/lovec.db  ──►  оценка (score.py): предфильтр → нейросеть → балл 0-100, причина, заход
        │
        ▼
 уведомление в Телеграм (notify.py): только 60+, свежее 3 дней, каждый — один раз
```

## Файлы

| Файл | Что делает |
|---|---|
| `lovec/search.py` | глобальный поиск Телеграма по фразам; `--probe` проверяет одну фразу |
| `lovec/score.py` | оценка: сначала грубый предфильтр без модели, потом пачки по 15 через выбранную нейросеть (`llm.py`) |
| `lovec/notify.py` | отправка горячих твоим ботом; `setup` находит chat_id, `test` шлёт пробное |
| `lovec/run.py` | один прогон: три шага + замок + сводка + тревоги |
| `lovec/doctor.py` | проверка готовности по пунктам; по ней онбординг знает, где остановился |
| `lovec/leads.py` | посмотреть находки, статистику по фразам, переоценить |
| `lovec/schedule.py` | расписание (cron на Linux, LaunchAgent на Mac) |
| `lovec/login.py` | вход в Телеграм; код и пароль вводятся скрыто |
| `lovec/secret.py`, `envset.py` | запись секретов (скрыто) и настроек в `data/.env` |
| `lovec/llm.py` | чем оценивать: Claude Code, Codex, Gemini CLI, Qwen Code, API в формате OpenAI, своя команда |
| `onboarding/` | пошаговая настройка для помощника в твоём офисе |
| `skills/lovec-daily/` | повседневный скилл |

## Что хранится и где

Всё личное в `data/` (в git не попадает): `.env` (ключи, права 600), `session.session` (вход в
Телеграм), `lovec.db` (находки), `niche.md`, `phrases.txt`, `changes.md`, `run.log`.

## Настройки (в `data/.env`, все необязательные)

| Ключ | По умолчанию | Что |
|---|---|---|
| `LOVEC_MIN_NOTIFY` | 60 | с какого балла присылать |
| `LOVEC_MAX_AGE_DAYS` | 3 | пост старше не присылаем |
| `LOVEC_MAX_NOTIFY_PER_RUN` | 5 | потолок уведомлений за прогон |
| `LOVEC_MAX_SCORE_PER_RUN` | 150 | потолок оценок моделью за прогон |
| `LOVEC_LOOKBACK_DAYS` | 7 | история при первом поиске по новой фразе |
| `LOVEC_ACTIVE_HOURS` | 8-22 | когда прогоны работают (время машины) |
| `LOVEC_LLM` | автоопределение | чем оценивать: `claude`, `codex`, `gemini`, `qwen`, `api`, `cmd` |
| `LOVEC_MODEL_BULK` / `LOVEC_MODEL_HOT` | у Claude haiku / sonnet, у остальных — умолчание программы | модели оценки |
| `LOVEC_API_BASE` / `LOVEC_API_MODEL` / `LOVEC_API_KEY` | — | API в формате OpenAI (ключ — через `secret.py`) |
| `LOVEC_LLM_CMD` | — | своя команда: задание в stdin, ответ в stdout |
| `LOVEC_CLAUDE_BIN`, `LOVEC_CODEX_BIN`, `LOVEC_GEMINI_BIN` | автоопределение | путь к программе, если не нашлась сама |
| `TG_NOTIFY_THREAD` | — | номер темы, если шлёшь в группу с темами |

Правки через `<PY> lovec/envset.py КЛЮЧ ЗНАЧЕНИЕ` (`<PY>` — `./venv/bin/python` на Mac/Linux, `venv\Scripts\python.exe` на Windows).

## Известные ограничения

- Поиск видит группы, где состоит аккаунт; чужие закрытые чаты недоступны.
- Телеграм иногда ограничивает частоту запросов (флуд-лимит); поиск ждёт и продолжает, а слишком
  долгие паузы пропускает до следующего прогона.
- Оценка зависит от лимита подписки выбранной нейросети.
- Работает на Windows, Mac и Linux. Расписание идёт, пока компьютер не спит.
