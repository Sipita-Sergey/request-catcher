# Инструкция для ИИ-агента: установить «Ловца запросов»

Ты помогаешь пользователю поставить **Ловца запросов**: он следит за группами в Телеграме, находит
людей, которые прямо сейчас ищут то, что делает пользователь, оценивает их и присылает горячих в
Телеграм с готовым заходом. Пользователь, скорее всего, не программист: веди его без жаргона и
говори, что именно происходит.

**Цель установки:** ловец стоит, настроен под нишу пользователя и сам присылает уведомления. Настройка
большая (бот, ключи, вход в Телеграм, чаты), поэтому её ведёт отдельный файл с шагами. Твоя задача
здесь только поставить комплект и передать управление ему.

## Шаг 0. Есть ли у тебя терминал или доступ к файлам компьютера?

Ловец живёт на компьютере: ему нужны Python, расписание и Claude Code. В браузерном чате его не
поставить. Не знаешь точно, есть ли у тебя терминал, выполни простую команду (`echo ok`). Не вышло:
у тебя его нет.

**Терминала нет.** Ответь пользователю ровно этим сообщением, ничего не добавляя:

> Ловец запросов работает на компьютере, а не в чате: ему нужно расписание и доступ к файлам. Для
> установки нужен помощник с доступом к компьютеру: например Claude Code, Codex или Cursor. Поставьте
> любой из них, откройте в нём папку для ловца и отправьте ему то же сообщение, что отправили мне:
> «Установи ловца запросов по инструкции https://raw.githubusercontent.com/Sipita-Sergey/request-catcher/main/INSTALL-FOR-AI.md»

**Терминал есть.** Иди дальше.

## Шаг 1. Выбери место

- У пользователя есть **офис** (папка с `CLAUDE.md`, куда он ставит свои скиллы и заметки): ставь комплект
  **рядом с офисом, не внутрь** (например `~/request-catcher`, если офис в `~/office`). Внутри комплекта
  появятся ключи и вход в его Телеграм, их нельзя смешивать со снапшотами офиса.
- Офиса нет: `~/request-catcher`.

Windows: нужен WSL (Ubuntu). Без него не ставь, а скажи пользователю об этом словами.

## Шаг 2. Скачай комплект

```bash
git clone https://github.com/Sipita-Sergey/request-catcher.git ~/request-catcher
```

Нет `git`: скачай `https://github.com/Sipita-Sergey/request-catcher/archive/refs/heads/main.zip`,
распакуй, папку назови `request-catcher`.

## Шаг 3. Передай управление онбордингу

Прочитай `~/request-catcher/onboarding/SKILL.md` и веди настройку **строго по нему**. Это не
пересказ, а рабочий процесс: он определяет, что сделать самому, а что только с пользователем, и
после каждого шага сверяется с проверкой готовности (`lovec/doctor.py`).

Что пользователю придётся сделать **руками** (скажи ему это сразу, чтобы не было сюрпризов; на всё
около 20 минут):

1. Получить ключи приложения Телеграма на my.telegram.org.
2. Ввести код входа из Телеграма (его присылают в приложение).
3. Создать своего бота в @BotFather для уведомлений.
4. Вступить в 10-30 тематических групп, где его клиенты задают вопросы (ловец ищет только в них).

Всё остальное делаешь ты. **Ключи, токен бота и код входа в чат не принимай:** они вводятся
командами `set-secret.sh` и `login.sh` скрытым вводом, мимо тебя.

## Правила ответа

- Первым ответом после запуска скажи, что будет и сколько займёт, и сразу начинай шаг 0 онбординга.
  Не спрашивай «начинать ли».
- Не оставляй пользователя без следующего действия: после каждого шага говори, что дальше.
- Ловец ничего не пишет от имени пользователя и не вступает в чаты. Скажи ему это до входа в Телеграм.

## Обновление

```bash
cd ~/request-catcher && git pull
```

Если в офисе стоят скиллы ловца, после обновления повтори
`./venv/bin/python lovec/install_skills.py <папка-офиса>`.
